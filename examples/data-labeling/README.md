# Data labeling quality mini-lab

面向文本分类的轻量标注练习，使用 5 条人工构造的学生服务请求演示标签定义、双人复核、缺失标注检查和一致性统计。Python 标准库实现。

## 运行

在仓库根目录执行（Python 3.8+）：

```bash
python examples/data-labeling/label_quality.py
python -m unittest discover -s tests -p "test_examples.py" -v
```

脚本只读取同目录的合成 `sample_tasks.jsonl`，不连接生产系统。输出 JSON 汇总：5 条任务、4 条双人完整标注、3 条一致，双人一致率 0.75、完整标注覆盖率 0.8；复核队列包含 1 条冲突和 1 条缺失标注。

## 标签指南与字段

| 标签值 | 定义 | 边界 |
| --- | --- | --- |
| `academic` | 课程、作业、学习资料 | 校园服务手续归 `campus_services` |
| `campus_services` | 报修、校园卡等生活与行政服务 | 明确寻求情绪支持时归 `wellbeing_support` |
| `wellbeing_support` | 情绪支持渠道咨询 | 仅表示请求类型，不构成健康诊断 |
| `other` | 不属于上述类别或信息不足 | 保留人工复核机会，不推断敏感信息 |

每行字段为唯一字符串 `id`、合成 `text` 和 `labels`。`labels` 是标注人 ID（`ann-a`、`ann-b`）到上述标签值的映射，字段名和标签值统一使用英文。空映射、只有一名标注人的任务会进入 `incomplete` 队列。未知标签、未知标注人或重复 ID 会报错，防止统计被静默污染。

## 如何解释统计

- 一致率 = 双人标签一致的任务数 / 双人标注完整的任务数。
- 完整标注覆盖率 = 双人标注完整的任务数 / 全部任务数。
- 没有完整任务时，一致率为 `null`（无定义）；单人标注不能算一致。
- 同时报告每名标注人的标签分布与一致任务标签分布；后者不是全部样本的最终标签分布。
- 冲突不自动多数投票覆盖。先复查指南，再记录裁定者和修改理由；本脚本尚未实现裁定持久化。

这 5 条合成文本只验证计算路径，不是标注质量实验，也不足以估计真实人群指标。后续可扩展独立标注、指南版本管理、分层抽样、Cohen's kappa 和置信区间；这些分析目前尚未实现。
