# Feature engineering | 特征工程笔记

特征工程的目标不是制造更多列，而是把可用信息转换成不泄漏、可复现、与任务一致的变量。

## 常见转换

- 类别特征：频次编码、独热编码或带平滑的目标编码。目标编码必须在训练折内计算。
- 时间特征：星期、月份、距上次事件的间隔。注意节假日表和时区版本。
- 文本特征：词袋、TF-IDF 或预训练模型向量。预处理规则要随模型版本保存。
- 聚合特征：历史次数、近 7 天计数、平均处理时长。聚合窗口的结束时间不能晚于预测时点。

## 质量检查

检查缺失率、唯一值数量、异常范围、分布漂移和训练/验证差异。对每个重要特征写清楚：来源、计算窗口、缺失含义、允许的更新频率。

## 一个常见泄漏

如果用“最终处理结果”去预测“是否需要人工复核”，模型会看见答案。正确做法是只使用决策发生之前可获得的字段，并在文档中标记字段的可用时间。
