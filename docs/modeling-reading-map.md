# Modeling notes reading map

建议按以下顺序阅读：

1. [Modeling basics](./09-modeling-basics.md)：任务定义、基线和诚实切分。
2. [Feature engineering](./10-feature-engineering.md)：特征来源、时间窗口和泄漏检查。
3. [Evaluation and error analysis](./11-evaluation-error-analysis.md)：指标、分层评估和误差复盘。
4. [Model interview notes](./12-model-interview-notes.md)：常见模型问题的结构化回答。

这些笔记是学习记录，不替代针对具体数据集的实验。阅读时应继续追问：数据从哪里来、预测时能否获得、指标是否匹配代价、结论能否复现。
