# Reviewer entry

## What this repository demonstrates

Small, readable examples connecting front-end reliability, data analysis, data labeling, and public-data collection boundaries.

## Suggested path

1. Read [`docs/README.md`](./docs/README.md) for the learning-note map.
2. Open [`examples/data-labeling/`](./examples/data-labeling/) for agreement and conflict review.
3. Open [`examples/public-crawler/`](./examples/public-crawler/) for robots.txt, rate limiting, scope control, and audit fields.
4. Follow [`docs/modeling-reading-map.md`](./docs/modeling-reading-map.md) for modeling and evaluation notes.
5. Use [`docs/experiment-card-template.md`](./docs/experiment-card-template.md) to review how a result should be documented.

## Evidence boundary

Examples use synthetic inputs or public page metadata. The repository does not contain student records, private credentials, internal data exports, or unauthorized web content.

## What is not claimed

These are educational and research-preparation examples. They do not claim a production crawler, a validated model, or a measured institutional outcome. Any future result should include data version, split strategy, metrics, error analysis, and limitations.
